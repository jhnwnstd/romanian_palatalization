## lexicon_raw

`data/czech/czech_lexicon_raw.csv`: the tracked raw lexicon: one row per lexeme with the columns extracted from its primary entry only (nothing derived); proper names and multiword expressions are left out (they are in lexicon_full). Written by `lexicon.py` (stage `lexicon`); tracked; licence class by-sa.

| Column | Type | Provenance | Description |
|---|---|---|---|

| `etymology_summary` | str | wiktionary | the deciding etymology template, summarized: kind:lang:term for a source (inh:zlw-ocs:kniha), the kind alone for an internal formation (af); lexpipe.etymology.summary |
