# Italian data dictionary

Generated by the `docs` stage from `docs/italian/schema.toml` (`lexpipe.langs.italian.schema`); edit the schema, not this file.

Types: `bool` cells are `True`/`False` (R10), `list` cells are `|`-joined, empty cells are missing values. Provenance: `wiktionary_en`, `wiktionary_it`, `morphit`, `leipzig` (corpus counts), `module` (Module:it-common port), `curated`, `derived`. Licence: `by-sa` (Wiktionary, Morph-it!), `unverified` (Leipzig counts: never in tracked files, R9), `citation` (hand adjudication).

## `data/italian/italian_lexicon_raw.csv`

The tracked raw lexicon: one row per noun/adjective lexeme of the en.wiktionary Italian split, with the extracted columns only (nothing derived), sorted by lexeme_id; out-of-domain proper names (domain capitalized) and multiword expressions are left out (they are in italian_lexicon_full.csv).

Stage `lexicon`; header `lexpipe.langs.italian.lexicon:RAW_FIELDS`; tracked.

| column | type | allowed | provenance | licence | description |
|---|---|---|---|---|---|
| `lexeme_id` | str |  | derived | by-sa | {lang}:{word}:{pos}:{ety}:{fp} (R4; lexpipe.ids) |
| `word` | str |  | wiktionary_en | by-sa | headword as written (NFC) |
| `pos` | enum | `noun`, `adj` | wiktionary_en | by-sa | part of speech of the entry |
| `gender` | enum | `m`, `f`, `mf`, `mfbysense`, `n`, `?` | wiktionary_en | by-sa | base of the first gender code of the head |
| `head_args` | list |  | wiktionary_en | by-sa | the head templates as written, one item each: key=value pairs joined by ';' (backslash-escaped), prefixed with 'name:' unless the template is it-noun (nouns) or it-adj (adjectives); lexpipe.kaikki.head_args |
| `ipa_raw` | str |  | wiktionary_en | by-sa | primary transcription as written (delimiters, stress, syllable dots) |
| `etymology_summary` | str |  | wiktionary_en | by-sa | the deciding etymology template, summarized: kind:lang:term for a source (inh:la:amīcus), the kind alone for an internal formation (af); lexpipe.etymology.summary |

| `source` | str | `wiktionary_en` | derived | by-sa | source of the row (R9) |
